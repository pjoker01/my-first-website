TECHNICAL SEO · LOCAL SEARCH · PRETORIA

Make your website easier to find, understand and trust.

PJ Web Development helps businesses identify and fix technical and on-page SEO problems that can make important pages harder to crawl, understand or discover. We work from evidence, explain what matters and verify the changes we make.

01 / CRAWLABILITY

Help search engines reach the right pages

Review robots.txt, XML sitemaps, HTTP status codes, redirects, internal links and canonical URLs. Find broken destinations and crawl paths that hide important content.

02 / INDEXABILITY

Check what should—and should not—be indexed

Inspect index directives, canonical signals, duplicate URLs and page availability. Where Google Search Console access is available, compare the website crawl with Google's reported indexing information.

03 / ON-PAGE SEO

Make every important page clearer

Review page titles, descriptions, headings, visible content, image alternatives and internal-link wording. Improve each page around a clear search intent rather than repeating keywords.

04 / STRUCTURED DATA

Describe your business and services accurately

Check JSON-LD for valid types, useful properties and consistency with visible page content. Add or correct business, website, webpage and service details without inventing reviews or business facts.

05 / LOCAL SEO

Strengthen local relevance and consistency

Improve location and service-area information, contact details, location-linked page content and local business markup. Google Business Profile checks require access to the actual profile; website markup alone does not prove profile verification or map rankings.

06 / PERFORMANCE

Measure speed instead of guessing

Use available Lighthouse or PageSpeed measurements to identify slow resources, image weight, render-blocking work and layout shifts. Core Web Vitals field data is reported separately from lab tests and may be unavailable for low-traffic URLs.

07 / JAVASCRIPT & AI ACCESS

Check what crawlers can actually read

Compare the initial HTML with rendered content where supported, and inspect crawler access rules for search and answer engines. Important page information should not depend on an interaction that crawlers cannot trigger.

08 / SEARCH CONSOLE

Use Google's own evidence when connected

With authorised Search Console access, review query performance, clicks, impressions, page indexing and sitemap status. Without that connection, reports must clearly say that Google-owned data was not checked.

HOW AN SEO ENGAGEMENT WORKS

Find the cause. Fix the right thing.

A useful audit should give you more than a percentage. It should show the issue, where it was found, why it matters and how to verify the fix.

01 — Crawl
Map the pages and inspect technical signals.

02 — Diagnose
Separate confirmed problems from warnings and unavailable data.

03 — Prioritise
Rank issues by impact, scope and confidence—not by a made-up score.

04 — Implement
Apply approved fixes while preserving useful URLs and content.

05 — Verify
Re-crawl, compare before and after, and record anything still blocked by access or external systems.

SEO QUESTIONS

Can you guarantee that my website will rank first on Google?

No. Nobody can honestly guarantee a specific Google position. Rankings depend on competition, relevance, site quality, links, location, search intent and Google's systems. We focus on measurable improvements and clear reporting.

Does a 98% SEO score mean my website is fully optimised?

Not necessarily. A score is only as useful as the checks behind it. A strong report should show the pages tested, evidence collected, missing data, failed links, crawl and indexing issues, and the difference between lab measurements and real-user data.

Can you check Google Search Console?

Yes, when you authorise access to the correct property. Without access, we can inspect the public website but cannot claim to have checked Google's private clicks, impressions, queries or indexing reports.

Can you improve my Google Maps visibility?

We can improve website-side local signals and review an authorised Google Business Profile. Maps visibility also depends on profile accuracy, relevance, distance, prominence and other factors outside the website.

Do you test website speed and Core Web Vitals?

We can run available lab tests and inspect field data when Google has enough real-user data. A Lighthouse score is not the same thing as a field Core Web Vitals result.
